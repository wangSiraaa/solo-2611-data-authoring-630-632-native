本目录是题目的离线输入起点，不含目标系统实现。

case.json给出可手算的小型业务数据和核对点；深度、潮位、吃水及净空单位是整数厘米，时间单位是整数分钟。输入是示例，交付须按题面规则处理其他合法输入和事件顺序。候选自行建立持久数据、运行入口和验证。

cell字符串是本样例整数网格坐标的固定别名：x=(0,0)，y=(1,0)。before、shallower、deepened、request.cells、routes以及核对点中的x/y都使用这同一映射；它们不是任意文字位置，也不改变题面以整数坐标识别方形单元的要求。A和B是两条命名航线，shared是两线共同占用且容量为1的航段。expected.before与expected.after是在相同预约请求下对水深换版前后的对照，不能把两次对照当成另建两条同号预约。additional_actions是需按题面展开的演示场景摘要。
