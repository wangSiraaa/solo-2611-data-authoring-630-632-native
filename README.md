本目录是题目的离线输入起点，不含目标系统实现。

case.json给出可手算的小型业务数据和核对点；金额及日期单位以题面为准。输入是示例，交付须按题面规则处理其他合法输入和事件顺序。候选自行建立持久数据、运行入口和验证。

本样例只有一组保障，policy=P1、device=D1；request.claim（C1）省略的保单和设备关联均指P1/D1，additional_actions里该案件的修订、暂停、恢复也沿用同一关联。accepted_commitments=[40,30]是C1此前两笔已生效支付承诺的金额摘要，可分别记为pay-1和pay-2；它不是完整支付动作格式，也不是两次尚待接受的新请求。request.id=pay-3表示本次20分的新请求。核对点在相同既有承诺下分别检查上限100和50，不能把两个对照当成连续接受同一笔新付款。additional_actions是演示场景提示，开发者需按题面补全真实动作所需的稳定身份与字段，不能将摘要省略字段解读为允许业务状态缺少身份。
